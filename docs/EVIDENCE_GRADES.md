# 근거 등급 재평가 (2026-10-14)

`backtest/evidence_upgrade.py`가 모든 주장을 **같은 규칙**으로 다시 판정한다(주간 재계산에 포함). 결과: `data/results/evidence_tests.parquet`, 화면은 홈·월가 자금·근거·방법.

## 규칙
- **검증됨**: 세 구간 모두 부호가 같고, 그중 2개 이상 구간에서 |t|≥2, 전체(합산) |t|≥3
- **단서**: 전체 |t|≥2이고 세 구간 중 2개 이상이 같은 부호
- **참고**: 그 밖의 모든 경우
- t는 Newey-West(lag = 수익률 겹침 길이), 횡단면 신호는 시점별 스피어만 IC의 시간 평균, 구간 끝의 미래 윈도우는 버린다(purge).
- 한 주장을 여러 호라이즌으로 쳐서 합격한 것만 고르지 않도록 **대표 검정을 사전에 하나로 지정**(`PRIMARY`). 나머지는 보조.
- 구간: 미국 ETF·한국 종목·AI는 2005–18 / 2019–22 / 2023~(AI는 2010~), 산업 모멘텀은 1927–62 / 1963–99 / 2000~, 팩터 모멘텀은 1963–89 / 1990–2009 / 2010~.
- 규칙의 일부는 탐색 결과를 일부 본 뒤에 문서화했다. 그래서 **이 등급은 '과거 기준'이며 전향 장부(H1~H7)가 쌓여야 확정**된다.

## 한국 전달 모델 v2
후보 4세트(기존 / +원달러 / +직전 외국인 z / +원달러·HYG·VIX·직전 z)를 사전에 정함 → train(~2018) 적합 → val(2019–22)로 선택(C) → train+val 재적합 후 test(2023~) 평가. 표본외 상관 0.33→0.45, 설명력 10%→20%.

## 탐색적 분해 (등급에 쓰지 않음)
미국 ETF 자금 역방향이 2019–22에서만 반대인 이유를 6개 조건(VIX 높음/낮음, SPY 200일선 위/아래, 자금 분산 큼/작음)으로 나눠 봤다. 일관된 것은 VIX 순위<0.5(세 구간 모두 음수, 전체 t −2.6) 하나이고, 다중 비교라 H5로 전향 등록했다.
